# Historical execution and design notes

These notes date from before the project was renamed from MeshDB to Nabedra
Database, and we kept their original text. Mentions of MeshDB, old imports,
commands, local checkout paths and AWS resource names describe the work as it
was done, not how to use the project today. We didn't rewrite or rerun the
measurements, commits or results for the rename. For current commands, see the
repository README and the component guides.

The `meshdb-testing` S3 bucket really is still called that. The acceptance
scripts only allow live runs against that bucket.
