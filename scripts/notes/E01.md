# Helper interface

```python
from acceptance_support import load_config

config = load_config()  # Repository .env, or pass an explicit local Path.
namespace = config.allocate_prefix(2, "types-crud")
# namespace.prefix is test-2-types-crud-<random-run-id>/
key = namespace.key("fixtures/rows.parquet")
child_env = config.server_env(namespace)
```

`load_config` supports optional `export`, assignment whitespace, single and double
quotes, and comments. Values remain literal, including shell substitutions and
variable references. Within double quotes, escaped quotes, backslashes, dollar
signs, and backticks are unescaped without evaluation. Multiline assignments,
shell statements, duplicate keys, and malformed quotes raise sanitized
`ConfigError` messages. Ambient AWS configuration is ignored.

`config.bucket` and `config.region` are safe metadata. The required AWS variables
stay private; an optional AWS_SESSION_TOKEN is also retained. BUCKET_NAME alone
selects the bucket. Dotenv MESHDB_* values do not override it.

`allocate_prefix(number, test_name, run_id=None)` requires numbers 1 through 9999
and lowercase alphanumeric segments with internal hyphens, each at most 64
characters. It generates a random run ID by default and rejects duplicate
allocations within the same configuration. Keep the returned namespace for
restart scenarios. An explicit run ID supports reproducing a recorded namespace;
callers must use fresh run IDs for separate runs.

`namespace.key(relative_path)` validates each object path segment and returns a
key beneath the allocated prefix. Absolute paths, empty segments, traversal,
backslashes, and encoded path syntax fail. `server_env(namespace)` requires a
namespace allocated by that configuration and never defaults to the bucket root
or `meshdb-v0/`.

`server_env` returns a private environment fragment with explicit AWS settings,
MESHDB_S3_BUCKET, MESHDB_S3_PREFIX and a locally generated MESHDB_TOKEN. The token
is created on the first call and reused for subsequent calls on that config.
The fragment omits ambient settings and disables AWS credential files, profiles,
metadata discovery, and CLI paging. Later launch tasks must add needed launch
settings without overriding its bucket or prefix. Environment representations
are redacted, but the returned mapping contains secrets. Do not print or serialize
it, expand it in exception diagnostics, or pass credentials in command arguments.

`config.preflight()` returns a PreflightResult containing success, bucket, region
and a fixed sanitized actionable error on failure. It does not allocate a prefix
or generate a bearer token. No process launcher or cleanup helper is included.
Preserve future fixtures for inspection.
