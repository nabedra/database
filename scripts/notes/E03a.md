# E03a local TLS material

`scripts/test_tls_material.py` is an import-safe Python 3.11 standard-library
helper. `create_test_tls(directory: Path) -> TLSMaterial` returns absolute
`server_cert`, `server_key`, and `ca_cert` paths. The parent directory must exist;
the destination must not exist. Existing destinations raise `FileExistsError`
without changing their contents. Other preparation failures raise
`TLSMaterialError` with fixed diagnostics and no OpenSSL output.

Generation uses the installed `openssl` on PATH, with `/opt/local/bin/openssl`
as a fallback. Each subprocess has a 30-second timeout, no shell, closed stdin,
and discarded stdout/stderr. This machine used OpenSSL 3.2.0. No external
service, AWS configuration, credentials, or dotenv files are involved.

The directory uses mode 0700. Both RSA-2048 private keys use mode 0600 before
OpenSSL writes them. The CA and CA-signed server certificate expire after two
days. The server certificate has IP SAN `127.0.0.1`, DNS SAN `localhost`, and
`serverAuth` extended key usage. The fixture directory also retains `ca.key`,
`server.csr`, and the static `openssl.cnf`. Callers own cleanup, including partial
fixtures after failure. The helper never removes files.

Integration for E03, with `scripts` on the Python import path and the existing
`config` and `namespace` supplied by its caller:

Verification ran from the repository root on 2026-11-10. The following command
passed after one fixture generation. Before implementation, the same check
failed because `test_tls_material` did not exist. No additional unit suite or

```sh
PYTHONDONTWRITEBYTECODE=1 orm/.venv/bin/python - <<'PY'
import hashlib
import shutil
import ssl
import stat
import subprocess
import sys
import tempfile
from pathlib import Path

sys.path.insert(0, str(Path('scripts').resolve()))
from test_tls_material import create_test_tls

openssl = shutil.which('openssl') or '/opt/local/bin/openssl'
with tempfile.TemporaryDirectory(prefix='meshdb-e03a-') as root:
    directory = Path(root) / 'tls'
    material = create_test_tls(directory)
    assert stat.S_IMODE(directory.stat().st_mode) == 0o700
    for key in directory.glob('*.key'):
        assert stat.S_IMODE(key.stat().st_mode) == 0o600
    assert material.server_key.is_file()
    for flag, name in [('-verify_ip', '127.0.0.1'), ('-verify_hostname', 'localhost')]:
        subprocess.run([openssl, 'verify', '-CAfile', str(material.ca_cert),
                        '-purpose', 'sslserver', flag, name, str(material.server_cert)],
                       check=True, timeout=30, stdin=subprocess.DEVNULL,
                       stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    context = ssl.SSLContext(ssl.PROTOCOL_TLS_SERVER)
    context.load_cert_chain(material.server_cert, material.server_key)
    ssl.create_default_context(cafile=material.ca_cert)
    before = {p.name: hashlib.sha256(p.read_bytes()).digest() for p in directory.iterdir()}
    try:
        create_test_tls(directory)
    except FileExistsError:
        pass
    else:
        raise AssertionError('Existing directory was accepted')
    assert before == {p.name: hashlib.sha256(p.read_bytes()).digest() for p in directory.iterdir()}
print('PASS: CA chain, IP/DNS SANs, serverAuth, SSL parsing, private modes, overwrite refusal')
PY
```
