## Integration contract

`meshdb_server::engine` now exports the production `Engine<B: ObjectStore>`.
Its private child modules are `query`, `mutation`, `read`, and `write`.
Existing lifecycle, read, and mutate methods are available on that same Engine.
`engine::MutationResult` re-exports the existing untagged Null, Count(usize), and
Found(bool) result so callers can name the return type of `mutate`.

The new public async method is:

```rust
Engine::execute(&self, Operation) -> Result<ExecuteResult, ProtocolError>
```

`engine::ExecuteResult` derives Debug and Serialize and is untagged. Its owned
variants serialize directly as response data without conversion through JSON:

| Operations | ExecuteResult | Wire data |
| --- | --- | --- |
| create, describe | Descriptor(TableDescriptor) | descriptor object |
| list | Descriptors(Vec<TableDescriptor>) | descriptors sorted by name |
| drop | Null | null |
| insert, upsert | Mutation(MutationResult::Null) | null |
| insert_many | Mutation(MutationResult::Count(usize)) | integer |
| update, delete | Mutation(MutationResult::Found(bool)) | boolean |
| get | Row(Option<Row>) | row object or null |
| collect | Rows(Vec<Row>) | row array |
| count | Count(u64) | integer |
| explain | Explain(String) | string |

Dispatch exhaustively matches all thirteen variants and delegates to completed
methods. It adds no retries, error mapping, request UUID handling, or runtime.
Every downstream ProtocolError code, message, and outcome propagates unchanged.

`Operation::name(&self) -> &'static str` returns the exact wire name.
`Operation::is_mutation(&self) -> bool` exhaustively classifies create, drop,
insert, insert_many, update, upsert, delete as mutations and the six others as
reads. Deserialization and validation are unchanged.

R09 must initialize storage once, share clones of one Engine/coordinator, await
`execute`, and pass its successful typed data directly to R09a `encode_success`.
HTTP owns request IDs, envelopes, final serialized body limits, and admission.
The executor must retain and await admitted mutation futures across disconnects,
including their blocking jobs. Classification identifies potential writes even
when a particular operation makes no change. Preserve uncertain errors as
outcome_unknown/unknown.
