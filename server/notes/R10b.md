# R10b: command parser

Implemented `src/cli.rs`, Clap annotations on `src/config.rs`, additive `cli` and `config` module exports in `src/lib.rs`, the pinned Clap dependency and lock entries, and `tests/cli.rs`. Config's existing fields, constructors, accessors, and validation are unchanged. No main, runtime, storage, snapshot, plan, branch, commit, or push changes.

## Public contract for bootstrap

- `meshdb_server::cli::Cli` implements `clap::Parser` and `Debug`. Its public `command: Command` is required. With `use clap::Parser`, call `Cli::parse()` for process arguments or `Cli::try_parse_from(args)` for fallible parsing without process exit.
- `meshdb_server::cli::Command` implements `clap::Subcommand` and `Debug`. Its sole application variant is `Command::Serve(meshdb_server::config::ServeOptions)`. Destructure that variant and pass the options directly to `Config::from_env(options)` in future bootstrap.
- Existing `ServeOptions` now also implements `clap::Args`. There is no second options type or conversion layer. No internal parser helpers were added.
- The command name is `meshdb-server`; normal Clap help and package version reporting are enabled. Version reporting propagates to `serve`. Unsupported commands and unknown arguments fail.
- `serve` accepts `--host: IpAddr`, `--port: u16`, `--workers: usize`, `--queue-size: usize`, and optional `--tls-cert`/`--tls-key: PathBuf`. Defaults come directly from `ServeOptions::default()` and remain `127.0.0.1`, `8000`, `4`, `64`, and no TLS paths.
- Typed parsing rejects invalid IPs, out-of-range integers, and negative unsigned values. Queue size zero is accepted. Workers zero parses and then fails existing Config validation. Config also owns admission limits and TLS pairing/readability. Parsing never opens TLS files or reads environment settings. No AWS or token arguments or Clap environment bindings exist.

Both documented commands parse, including the TLS command with literal `cert.pem` and `key.pem` paths. This task does not create a runnable server.

## Dependency evidence

Clap is pinned to `=4.6.7` with `derive`. The [official derive reference](https://docs.rs/clap/4.6.7/clap/_derive/) documents `Parser`, `Subcommand`, tuple variants containing `Args`, inferred typed parsers, and `default_value_t` expressions. The downloaded registry source `clap-4.6.7/Cargo.toml` declares Rust 1.85, compatible with this package's Rust 1.94.1 minimum. Cargo selected compatible dependencies and changed no existing dependency versions.
