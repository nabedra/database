# Historical execution artifacts

The `cli-serverless/` and `resource-aware-scheduling/` folders record runs
completed before the rename to Nabedra Database. They retain their original
bytes, including the former MeshDB package, command and
source-path labels, source hashes, binary hashes, commit identities, timings and
failure outcomes. The original labels do not describe the current package or
CLI. Images and plots are also retained as historical results.

The rename did not rerun these benchmarks or acceptance scenarios. Current
reproduction commands appear in the surrounding evidence ledgers. Newly executed
checks must record their own tested revision and results rather than overwrite
this archive.
