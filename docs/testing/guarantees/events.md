# Events guarantees

Module: events
Level: L2

Each partition has its own Raft group. A retried publish keeps its topic,
partition, UUID, and body. Consumers acknowledge a contiguous prefix under
a lease generation. See the [Events plan](../../../plans/events.md) and
[Docker acceptance cases](../../../server/events/tests/README.md).

EV06 keeps local kind PVC checks. EV10 keeps local backup, restore, and
TLS checks, and the S3 parts still require real S3.
