# Vector guarantees

Module: vector
Level: L3

Vector, full-text, sparse and multi-vector search on OLTP tables, from the
[vector plan](../../../plans/oltp-vector.md). The module is designed and not
implemented. It is L3 because `latest` queries join OLTP's real-time order and
`SetVector` writes rows. The search workers' local index alone would be L2.

The simulator is not used in the first version (user decision, 2026-11-25).
Rows keep S and trace validation as required, so their cells stay `missing`
until those checks exist.
