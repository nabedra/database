# OLAP guarantees

Module: olap
Level: L2

Query semantics and the scheduler are L1. The commit protocol is L2. A
conditional catalog update publishes complete Parquet references and a
durable decision. The [scheduler contract](../scheduler-contract.md)
defines the T, U, resource, recovery, scaling, and benchmark scenarios.

R on OLAP-G01 to OLAP-G05 is the T01 to T06 suite run end to end against
real S3 with natural races only, together with
`scripts/acceptance_serverless_s3.py`. It is in scope and reports
`not-run: s3-unconfigured` until the test bucket exists. The local and
simulated stores reproduce injected failures such as a reply lost after
application and a delayed PUT. A01 and A02 keep their local kind cases.
