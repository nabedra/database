# P01 handoff

Implemented package metadata, public scalar/schema aliases and all specified error
classes, plus shared schema, row, key and scalar validation. Runtime dependencies
are standard library only; Python >=3.11 is required. Reused the existing
`orm/.venv` running Python 3.11.10 without replacing it.

Files: `orm/pyproject.toml`, `orm/src/meshdb/{__init__,errors,validation}.py`,
`orm/tests/test_validation.py`, and this note.

## Interfaces for following tasks

Public exports currently contain only `Scalar`, `Key`, `Row`, `Schema`,
`MeshDBError`, `ValidationError`, `AuthenticationError`, `NotFoundError`,
`ConflictError`, `LimitExceededError`, `OverloadedError`, `StorageError`,
`TransportError`, `ProtocolError`, and `UnknownOutcomeError`.

Every exception accepts `(message, *, code=None, request_id=None,
status_code=None, outcome=None)` and exposes those four diagnostic attributes.
Subclass codes default to their protocol codes; transport/protocol codes are
`transport_error`/`protocol_error`. Local validation and definite server failure
classes default to `not_applied`; transport/protocol/base errors default to no
outcome; `UnknownOutcomeError` defaults to `unknown`. Transport can supply the
server's code and diagnostics explicitly.

Internal reuse comes from `meshdb.validation`:

- `validate_identifier(value) -> str` and `validate_format(value) -> "parquet"`.
- `validate_schema(schema, *, key=None) -> Schema`. Pass a validated non-null key
  when validating table creation/descriptors; omitting it validates columns only.
- `schema_to_wire(schema) -> dict[str, str]` and
  `schema_from_wire(schema) -> Schema` validate columns and convert explicit types.
- `validate_value(value, expected_type, *, column="value") -> Scalar` is available
  for predicate builders; it enforces exact types, int64 bounds and finite floats.
- `validate_key(value, schema, key) -> Key` validates key schema and scalar.
- `validate_row(row, schema, *, key, partial=False) -> Row` validates full
  insert/upsert rows. `partial=True` permits empty updates but rejects any key
  field, even an unchanged key. Unknown/null/missing values are rejected as
  appropriate. Mapping inputs are copied; returned dictionaries are independent.
- `INT64_MIN`, `INT64_MAX`, `MAX_COLUMNS` are available internally.

Schemas above 128 columns raise `LimitExceededError`; other local invalid inputs
raise `ValidationError`. Transport must translate invalid response data into
`ProtocolError` or `UnknownOutcomeError` according to the operation. Keep a
private schema copy in handles and return copies from public schema properties.

## Validation

The initial test run failed because the package modules did not yet exist.
These commands then passed from the repository root:

```sh
orm/.venv/bin/python -m pip install -e ./orm
orm/.venv/bin/python -m unittest discover -s orm/tests -v
```

Five compact test groups cover mapping round trips and ownership, schema/name/
key/format errors, full/partial rows, exact scalar values and bounds, and exception
diagnostics/exports. No HTTP fixture or query tests were added.
