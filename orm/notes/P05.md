## Interfaces

Public API now exports DB, Table, Query, Expr, col, Scalar, Key, Row, Schema
and all existing public exceptions.

- `DB(api_url, token, *, timeout=30.0, ca_file=None)` constructs `_Transport`
  without HTTP. Its validation and TLS configuration remain authoritative.
- `DB.create_table(name, schema, key, *, format="parquet") -> Table` validates
  locally, translates schema types explicitly and decodes a strict descriptor
  inside the transport boundary. Returned name/schema/key/format must match the
  submitted metadata. Invalid successful mutation responses raise
  UnknownOutcomeError with request diagnostics.
- `DB.table(name) -> Table` describes once and requires the requested name.
  `DB.tables() -> list[Table]` sends `{}`, requires a descriptor list sorted by
  name, and rejects duplicate names or UUID identities, including case variants.
  Both retain server IDs without metadata lookups or handle refreshes.
- `Query.collect() -> list[Row]`, `count() -> int`, and `explain() -> str` each
  submit one fresh request with the retained table ID and fresh `_to_wire()`.
  Builders remain immutable and perform no I/O. Collect validates exact projected
  columns and scalars directly, permitting projections without the primary key.
  It rejects more than 10000 rows or the explicit limit. Count requires an exact
  nonnegative int within the explicit limit and the 100000-row table maximum.
  Explain accepts only text. Query limits gain no client maximum.

All operation decoders run inside `_Transport.request`. Malformed read results,
including oversized row/count results, raise ProtocolError. A valid server
`limit_exceeded` error remains LimitExceededError. The existing transport owns
the 8 MiB byte cap and mutation uncertainty mapping.
