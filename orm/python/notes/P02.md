# P02 handoff

Implemented immutable expressions and pure query construction/serialization only.
Files: `orm/src/meshdb/expr.py`, `orm/src/meshdb/query.py`, additive public exports
in `orm/src/meshdb/__init__.py`, `orm/tests/test_query.py`, and this note.

## Interfaces for P04 and P05

Public exports now include `Expr`, `col`, and `Query`, preserving P01 exports.
`col(name)` builds a column reference. Comparisons accept exact supported scalar
values; `&`, `|`, and `~` build logical expressions. Python boolean conversion
raises `TypeError`, as do expression-to-expression comparisons and callable
comparison operands. Bare column references and incomplete logical predicates
raise `ValidationError` when attached to a query.

P04 should implement `Table.query()` as `return Query(self)` and `Table.where()`
as `return self.query().where(expr, **filters)`. `Query(table)` needs only the
handle's `schema` mapping and `key` for construction. It retains that handle as
`query._table`, so P05 can obtain the immutable table ID and transport from the
real Table. The constructor copies and validates the schema through P01, then
stores a read-only mapping. Builders retain the original schema snapshot and
handle. The Table annotation is imported only under TYPE_CHECKING, avoiding a
runtime import cycle before or after table.py exists.

`Query.select(*columns)`, `.where(expr=None, **filters)`, `.order_by(column,
desc=False)`, and `.limit(n)` each return a new frozen query. Select/order/limit
replace settings; where combines the existing predicate, explicit predicate and
keyword equalities in an AND node. Empty where returns a new equivalent query.
Expression nodes contain only tuples and exact immutable scalars. All column,
scalar and schema checks reuse P01 helpers; boolean ordering is rejected after
schema validation. A comparison has depth one; the maximum predicate depth is
32, including AND nodes introduced by repeated where calls.

P05 should use `query._to_wire()` as the `query` field of its operation payload.
It returns fresh JSON-safe dict/list data with all four keys, `select`, `filter`,
`order_by`, and `limit`, defaulting to None. Mutating any returned nested dict or
list cannot change the query. `Expr._to_wire(schema)` is the internal validating
predicate serializer. `_node`, `_from_node`, and Query state fields are private
implementation details, not inputs for callers. No execution method, transport,
HTTP fixture, result decoding or row evaluation was introduced.

Five compact query groups passed, then all ten ORM tests passed. They cover the
example wire payload and JSON encoding, detached output, immutable query

Python boolean misuse, unsupported operands and the depth boundary. Tests use a
small frozen table context with no transport. `git diff --check` also passed.
